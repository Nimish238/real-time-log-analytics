# Real-Time Log Analytics Pipeline

An end-to-end cloud data engineering project that processes application log data using PySpark and Medallion Architecture. The pipeline ingests raw JSON logs, transforms them into Bronze, Silver, and Gold layers, stores them in AWS S3, loads analytics-ready data into Snowflake, and visualizes insights using Power BI dashboards.

## Tech Stack

- PySpark
- AWS S3
- Snowflake
- Power BI
- Python
- SQL

## Features

- Real-time log processing using PySpark
- Medallion Architecture implementation
- Automated cloud data lake storage using AWS S3
- Snowflake cloud warehouse integration
- KPI and monitoring dashboards in Power BI
- Service performance and error analytics
- Response time and traffic monitoring
- 
## Project Architecture

Raw JSON Logs → PySpark ETL → Bronze/Silver/Gold Layers → AWS S3 → Snowflake Warehouse → Power BI Dashboard
